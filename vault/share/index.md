# 分享夾

她把這裡的東西挑來傳給你。支援 png / jpg / gif / webp / mp4 / webm / mov。

一行一個檔案，`|` 分隔：

```
- 檔名 | 標籤1,標籤2 | 一句話描述
```

- 標籤是給她檢索用的：情緒（笑死、翻白眼、摸魚）、場景（加班、吃、晚安）、對象。
- 沒寫在 index 裡的檔案也會被抓到，描述就用檔名。
- 她一次只發一張，而且會避開最近發過的。

範例（把檔案丟進來再照著寫）：

```
- cat-fail.gif | 貓,笑死,智障 | 貓咪跳失敗
- eye-roll.gif | 翻白眼,加班,抱怨 | 受不了的那種翻白眼
- rice.mp4 | 白飯,吃,討飯 | 扒飯扒到臉都是
```

空的也沒關係，只是她沒東西可分享。
